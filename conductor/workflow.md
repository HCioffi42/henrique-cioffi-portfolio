# Workflow

This project uses the Conductor extension for structured development.

## 1. Planning
- Use `enter_plan_mode` to research and design a feature or bug fix.
- Create a new **Track** in `conductor/tracks.md`.
- Draft a **Spec** and **Implementation Plan** for the track.

## 2. Implementation
- Execute tasks within a track's plan using the **Execution Cycle** (Plan -> Act -> Validate).
- Regularly update the track's metadata to reflect progress.

## 3. Testing & Validation
- Ensure all changes are covered by tests.
- Run tests before completing a track.
- Perform final architectural and style checks.

## 4. Finalization
- Update the **Tracks Registry** (`conductor/tracks.md`) to reflect the track's completion.
- Prepare a commit message if requested.
