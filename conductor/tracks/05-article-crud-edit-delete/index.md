# Track 05: Article CRUD (Update & Delete)

This track finalized the administrative lifecycle of the blog engine.

## Achievements
- **Full CRUD**: Implemented Update and Delete operations across the entire stack.
- **English Refactor**: Standardized the codebase to use English naming conventions (`Title`, `Summary`, `Content`, `CreatedAt`) for consistency.
- **Security Hardening**: Fixed a critical vulnerability in AutoMapper by upgrading to `15.1.3`.
- **Admin UX**: Created a professional Dashboard and a confirmation modal for destructive actions.

## Tech Stack
- .NET 8 (MediatR, AutoMapper 15, FluentValidation)
- React (Tailwind CSS, Axios, React Router)
